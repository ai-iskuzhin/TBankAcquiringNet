# TBankAcquiringNet.Multisplit.Payouts

Planned dependency-light .NET SDK package for T-Bank Multisplit payout flows.

This package is not published yet. It is reserved for A2C/e2c payout APIs, including payout initiation, payout status lookup, card payouts, SBP payouts, partner payouts, and certificate/signature request fields.
